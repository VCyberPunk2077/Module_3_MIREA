# Модуль 3 Kotlin

Учебное Android-приложение на Kotlin и Jetpack Compose для практических заданий модуля 3.

В проекте есть лента карточек профилей, светлая и тёмная Material-тема, журналирование жизненного цикла Activity, счётчик с состоянием во ViewModel, навигация между экранами и адаптивная компоновка для широкого окна.

## Запуск

Откройте каталог `Module3Kotlin` в Android Studio, дождитесь синхронизации Gradle и запустите конфигурацию `app` на эмуляторе или устройстве.

Сборка из командной строки:

```bash
./gradlew assembleDebug
```
